Anclave — 목업 구현 계획

정본 Anclave-시스템정리.html(IA 8 대분류·28화면)을 React + Vite + TypeScript + Tailwind 목업으로 만들기 위한 구현 가이드. 각 화면의 Goal·라우트·레이아웃·컴포넌트·더미·우선순위를 정의한다. 폐쇄망 공공 납품 전제 · 기능 없음(화면·전환·더미 표시만).

0목표 (Goal)

  • 전체: 28화면을 더미 데이터 기반으로 구현해 역할(A / B=C)·화면·흐름을 클릭 데모로 보여준다.
  • 품질: Q1~Q29 디자인 일관 적용. 공통 컴포넌트 재사용으로 화면 간 톤·밀도·동작 통일. "AI 티" 없는 절제된 완성도.
  • 비기능: 실제 API·인증·연산 없음. 라우팅·상태 전환·더미 시각화만. 다크/라이트 토글, 데스크톱 우선 반응형.
  • 산출물: app/ (Vite 프로젝트). 정본 문서가 사양서, 이 문서가 구현 가이드.

8/goal 실행 (단계별)

3개의 /goal을 순서대로. 각 Goal이 끝나면 검증·커밋 후 다음 Goal. 전 단계 공통 전제: 작업 폴더 app/, 사양 = Anclave-시스템정리·구현계획·디자인스펙.html 준수, 더미는 §5 시드대로 풍부하게, 디자인은 디자인스펙 픽셀값 정확 적용, 콘솔 에러 0.

/goal 조건문은 "§8 Goal N DoD를 모두 충족"으로 간결히 걸고, 실제 합격선은 아래 DoD 체크리스트로 판정한다. 각 항목은 검증 가능(파일 존재·빌드·렌더·픽셀값 일치)해야 한다.

ℹ️ /goal 조건문에는 turn 제한을 넣지 않는다(turn 수는 파일/렌더로 검증되는 DoD가 아님). 운영 메모로만: "30턴 초과 시 사람이 진행 상황 보고 중단 여부 판단".
