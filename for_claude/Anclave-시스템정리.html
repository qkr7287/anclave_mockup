2역할 & 권한

권한은 실질 2종: A 최종관리자 / B 실무관리자 = C 사용자 (권한 동일, 호스팅·받은 신청 유무로 화면만 다름). 사용자가 GPU 호스팅 받으면 그 범위에서 B가 됨. 재할당 불가(단말에서 종료).
목업 계정은 3개: admin / manager(호스팅 후 = B 화면) / user(호스팅 전 = C 화면) — user → manager 로 C→B 여정(호스팅 전→후)을 시연.

4.1 로그인 공통

하드코딩 3계정 (시연용)

  • manager — 호스팅 보유 사용자 (B 화면: 대시보드·승인·자원맵)

콘텐츠가 늘거나 길어져도 레이아웃이 밀리거나 잘리지 않게 한다. 가장 흔한 불만 두 가지를 원천 차단:
① 영역 크기 고정 — 한 번 정한 영역(카드·패널·차트)은 콘텐츠가 늘어도 크기 불변. 넘치면 레이아웃을 밀지 말고 내부 스크롤(overflow:auto) 또는 말줄임으로 흡수. 형제 영역으로 넘침·겹침·잘림 금지
② Flex/Grid 자식 넘침 차단 — 자식에 min-width:0(가로)·min-height:0(세로) 적용(이게 없으면 긴 텍스트·표가 컨테이너를 밀어냄). 고정 트랙은 px/minmax, 가변은 minmax(0,1fr)
③ 텍스트 오버플로 — 한 줄 유지 영역은 ellipsis(…) + title/tooltip. 줄바꿈 허용한 영역만 wrap. 글씨를 줄여서 욱여넣는 것 금지
④ 테이블 — table-layout:fixed + 컬럼 명시 너비. 헤더(제목)는 nowrap·크기 고정 — 절대 축소·2줄 줄바꿈 금지. 셀 넘침은 ellipsis, 숫자 컬럼은 고정폭·우정렬. 컬럼 수가 화면에 안 맞으면 글씨 축소가 아니라 컬럼 숨김/우선순위 드롭 또는 가로 스크롤로 처리
