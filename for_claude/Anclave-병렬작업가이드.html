0 · 한 줄 개념

  • worktree = 같은 저장소에서 폴더만 따로 만든 것. 폴더가 다르니 동시에 작업해도 안 부딪힘.
  • 브랜치 = 각 폴더가 자기 브랜치라, 끝나면 합치기(머지) 전까진 서로·기반에 영향 0.
  • deny = 그 폴더에서 공유 파일을 못 고치게 잠근 설정. 이미 넣어놨고, 폴더 열면 자동 적용.
네가 할 일은 딱 하나 — 아래 3개 폴더에서 각각 Claude Code 세션을 열고, 정해진 프롬프트를 붙여넣기. 끝.

2 · deny는 어떻게 "적용"되나? 제일 헷갈리는 부분

적용 버튼 같은 건 없습니다. 각 worktree 폴더 안에 이 파일이 들어있고:

..\anclave-g2\.claude\settings.local.json

그 폴더를 열어 Claude Code 세션을 시작하면 자동으로 읽힙니다. 그 세션은 아래 공유 파일을 고칠 수 없게 됩니다(읽기는 가능):

app/src/components/**   ← Shell·Header·Sidebar·UI·차트 등
app/src/data/**         ← 더미 시드
app/src/lib/**          ← theme·role·routes
app/src/App.tsx         ← 라우팅
app/src/index.css       ← 디자인 토큰

잘 잠겼는지 확인하는 법

세션을 연 뒤 시험삼아 이렇게 시켜보세요:

components/Shell.tsx 에 주석 한 줄 추가해봐
정상 = "권한이 거부되었다(denied)"며 못 고침. → 잠금 OK.
문제 = 그냥 고쳐버림. → .claude/settings.local.json이 그 폴더에 있는지·세션 cwd가 그 폴더인지 확인.

5 · 끝난 뒤 — 합치기(머지)는 내가

  1. 세션이 자기 브랜치에 커밋·②검증까지 끝내면 → 나(이 메인 세션)한테 "G2 끝났어"라고 알려줘.
  2. 내가 feat/g2-dashboard → feat/mockup-impl로 머지. 서로 다른 파일이라 충돌 0.
  3. 머지 끝나면 나머지 worktree는 최신 기반을 당겨옴:
    git -C ..\anclave-g5 rebase feat/mockup-impl
    (이것도 내가 해줄게.)
공유 파일을 고쳐야 한다고 세션이 말하면 → 그 세션은 deny로 못 고치니, 그 내용을 나한테 전달해줘. 내가 메인에서 고쳐 기반에 반영 → 각 worktree rebase. (예: 새 공통 컴포넌트·data 필드·디자인 토큰)

6 · 문제 해결

증상해결
deny가 안 먹고 공유 파일이 고쳐짐세션 cwd가 그 worktree 폴더인지 확인. .claude/settings.local.json이 그 폴더에 있는지 확인.
npm run dev 포트 충돌포트를 바꿔(5182→5183 등). 또는 이미 떠있는 dev 서버를 끄기.
가이드(localhost:8765)가 안 열림메인 anclave_mockup의 문서서버가 떠 있어야 함. 꺼졌으면 다시 켜기.
세션이 다른 화면 파일을 건드림자기 브랜치라 기반엔 영향 없음. 프롬프트에 "자기 파일만"을 다시 강조하거나 나한테 말해.
worktree 지우고 싶음내가 git worktree remove ..\anclave-g2로 정리.
